# PhotoWindow Brand Moodboard

Qualified intake:

- Business: PhotoWindow / 摄影窗口
- Goal: Define the brand style, palette, typography feel, and visual guardrails for the iOS MVP.
- Audience: astro, landscape, aviation, and campus graduation photographers.
- Visual language: cinematic dark, professional tool, weather radar, light community warmth.
- Palette: dusk cyan with restrained amber signal accents.
- Layout feel: large score badges, clean cards, editorial polish.
- Imagery: real photography scenes, interface-first moments, location-specific shooting windows.
- Avoid: overused purple-blue gradients, social feed cues, and mini mood-board collage tiles.
